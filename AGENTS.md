# The account-wide defaults

Design: `ARCHITECTURE.md` says what each piece owns and what it must not do. Read it first.
The most important rule is that this repository is public: never name a private repository,
a machine or any other piece of the estate here.

Work arrives as a build handoff in the vault's `05_Agents/handoffs/`. Changes reach `main` through
a pull request that Mark merges.
